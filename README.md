# Robotic Arm – CATIA V5

## 📌 Project Overview

A 3D CAD model and assembly of a robotic arm designed using **CATIA V5**.

The project includes individual part modelling, complete assembly, and 2D engineering drawings.

## 🎯 Objectives

- Design a multi-axis robotic arm using CATIA V5
- Create individual 3D components
- Assemble the components using appropriate constraints
- Create 2D engineering drawings
- Develop a complete CAD portfolio project

## 🛠️ Software Used

- CATIA V5
- Part Design
- Assembly Design
- Drafting

## 🧩 Components

| No. | Component |
|---|---|
| 01 | Base |
| 02 | Lower Arm |
| 03 | Upper Arm |
| 04 | Rotor |
| 05 | Jaw Holder Rotor Chuck |
| 06 | Jaw Holder Rotor |
| 07 | Jaw Holder |
| 08 | Gripper Jaw |

## 📦 Assembly

The individual components are assembled into a complete robotic arm using CATIA V5 Assembly Design.

## 📐 Engineering Drawings

2D drawings are provided for the individual components in DWG format.

## 📁 Project Files

The repository contains:

- CATIA V5 `.CATPart` files
- CATIA V5 `.CATProduct` assembly
- `.DWG` engineering drawings
- Assembly reference images
